# Next.js project Care – Baby Sitting & Elderly Care Service Platform

## Features
- Baby Care, Elderly Care & Sick Care Services
- Secure Authentication (Email & Google)
- Dynamic Booking System
- Booking Status Tracking
- Email Invoice on Booking
- Responsive Design

## Tech Stack
- Next.js (App Router)
- Firebase Authentication
- MongoDB
- Tailwind CSS
